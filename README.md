AI Reading List and Book Summary Manager

Project Description

ReadNest is a simple web application to manage books, create book summaries, and track reading progress.

Features

- Add books and author names
- Generate short summaries from entered text
- Search books
- Mark books as read or unread
- Save book details in the browser

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download the HTML file from this repository.
2. Open it using a web browser.
3. Enter book details and generate a summary.

Project Type

Student Mini Project
